# VeCare CPD System

基于**统计声学感知（SAS, Statistical Acoustic Sensing）**的车内儿童存在检测（CPD, Child Presence Detection）功能样机。

复用/模拟车载扬声器与单麦克风：扬声器发出宽频探测信号，麦克风接收经座舱多径传播的 CSI（信道状态信息），通过 CSI 振幅的自相关统计同时检测**体动**与**呼吸**，并在确认存在后 10 s 内触发告警。附带实时 Web UI 与 JSONL 会话日志回放。

> 本项目为**功能样机**，用于验证 SAS 检测链路与交互流程，**不做量产适配**、**不做多目标区分**、**不做速度估计**，也**未做真实新生儿大规模验证**。

## 功能

- **SAS 声学前端（仿真）**：50 Hz CSI、24 个子载波（10.5–23.5 kHz），静态座舱多径 + 弱目标反射 + 胸腔呼吸位移 + 体动 + 噪声/振动突发。
- **运动检测**：CSI 振幅去均值/去趋势无偏 ACF，1 Hz 高通后取 100 ms 时滞统计量 `g(f)`，子载波等权平均。
- **呼吸检测**：8 s 窗口 ACF 按 `g(f)` 做最大比合并（MRC），按峰高/显著度/宽度筛选呼吸峰，抛物线插值得到 `τ_b`，`BPM = 60/τ_b`，中位数平滑。
- **实时报警**：5 s 证据窗口内证据占比 ≥ 30% 确认存在；存在确认后 10 s 倒计时触发告警；确认呼吸后约 15 s 无呼吸升级为呼吸暂停（APNEA）告警；支持确认静音（ACKED）。
- **Web UI**：实时监测、座舱声学动画、4 个 Canvas 图表（运动统计 / BPM 趋势 / 合并 ACF / CSI 热力图）、事件流、真值对照（仅用于验证，检测链路不读取）。
- **日志回放**：JSONL 会话记录（`frames.jsonl` / `events.jsonl` / `meta.json`），支持播放、倍速、进度拖动、事件按仿真时间过滤与原始日志下载。

## 运行

依赖 Python 3.11+、numpy、scipy；测试需要 pytest。

```bash
pip install numpy scipy pytest

cd /workspace/vecare_cpd_system
python3 server.py --port 8090
```

浏览器打开 `http://127.0.0.1:8090`，选择场景后点击「开始监测」，可调整灵敏度与 1–16× 倍速。

## 测试

```bash
cd /workspace/vecare_cpd_system
python3 -m pytest tests -q
```

覆盖：ACF 周期峰、运动统计量、MRC 合并、呼吸峰提取、校准状态迁移、存在确认与 10 s 告警计时、APNEA 升级、确认静音，以及空车厢/睡眠婴儿离线场景指标。

## 场景与预期

| 场景 | 说明 | 预期 |
|---|---|---|
| 空车厢 | 仅背景噪声 | 不触发存在/告警 |
| 入睡婴儿 | 18 BPM 呼吸 | 确认存在后 10 s 内告警 |
| 活跃儿童 | 24 BPM + 肢体动作 | 确认存在后 10 s 内告警 |
| 呼吸暂停 | 42 s 呼吸停止 | 约 15–18 s 后升级 APNEA |
| 新生儿 | 30 BPM 弱反射 | 确认存在并告警 |
| 噪声振动 | 突发噪声与座椅振动 | 不误报 |
| 成人 | 14 BPM | 确认存在并告警（区分多目标不在范围内） |

## 模型说明

论文核心公式：

```
H(f, t) = Σ_r a_r(t) exp(-j2πf τ_r(t))
```

- 对每个子载波 CSI 振幅求 ACF：`ρ(f, τ)`；
- 运动统计量取小时滞抽头：`g(f) = ρ(f, 100 ms)`；
- 呼吸检测对子载波 ACF 做 MRC 合并：`ρ̂(τ) = Σ w(f) ρ̃(f, τ)`，`w(f) ∝ g(f)`；
- 在 1.0–5.0 s 时滞区间内选峰，`BPM = 60/τ_b`；
- 5 s 证据窗口占比 ≥ 30% 确认存在，确认后 10 s 响应。

## 范围限制

- 不含真实音频硬件采集，声学信道与目标反射均为仿真；
- 不区分车内多目标，不估计目标速度；
- 阈值与场景参数基于仿真调校，未经真实新生儿大规模数据验证；
- 不包含量产级标定、车规认证与嵌入式移植。
